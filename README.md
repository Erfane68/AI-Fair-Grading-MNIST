Visualizing Learner Handwriting: Identifying Unclear Handwriting and Flagging Potential Misinterpretations
Technologies: Python, PCA, t-SNE, scikit-learn, matplotlib, seaborn

Description:
This project uses dimensionality reduction techniques like PCA and t-SNE to identify and flag unclear handwriting in students’ submissions. By visualizing ambiguous clusters in a 2D space, the goal is to identify areas where the AI grading system might misinterpret handwritten input, allowing educators to address these issues for fairer grading.

Key Learnings:

Applied dimensionality reduction for error identification in AI grading systems.

Demonstrated how clustering can help flag potential misinterpretations of student handwriting.
